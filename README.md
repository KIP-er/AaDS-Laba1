# laba_1 — Вариант 1. Векторы

Шаблонный класс вектора произвольной размерности на C++23.  
Тип элемента вектора задаётся параметром шаблона `T`.

## Возможности

- Шаблонный класс `vector<T>` произвольной размерности.
- Поддержка типов:
  - `int`
  - `float`
  - `double`
  - `std::complex<float>`
  - `std::complex<double>`
- Конструктор с размерностью и значением для заполнения.
- Конструктор со случайными значениями:
  - размерность;
  - нижняя граница;
  - верхняя граница.
- Доступ к элементу по индексу через `operator[]` с проверкой границ.
- Операторы сложения и вычитания векторов.
- Оператор скалярного произведения векторов.
- Оператор умножения вектора на скаляр.
- Коммутативность умножения на скаляр: `v * k` и `k * v`.
- Оператор деления вектора на скаляр.
- Для комплексных чисел скалярное произведение использует сопряжение первого вектора:
  `sum(conj(a_i) * b_i)`.

## Требования

- CMake 4.1+ (как указано в `CMakeLists.txt`).
- Компилятор с поддержкой C++23 и `import std;`:
  - Clang;
  - GCC;
  - MSVC.
- Для сборки используются экспериментальные возможности CMake для `import std`.

## Основное API

| Метод | Описание |
|---|---|
| `vector(std::size_t size, const T& value)` | Создаёт вектор размера `size`, заполненный значением `value`. |
| `vector(std::size_t size, const T& lower, const T& upper)` | Создаёт вектор размера `size`, заполненный случайными значениями из диапазона `[lower, upper]`. |
| `T& operator[](std::size_t index)` | Доступ к элементу по индексу для чтения и записи. |
| `const T& operator[](std::size_t index) const` | Доступ к элементу по индексу только для чтения. |
| `vector operator+(const vector& other) const` | Поэлементное сложение векторов. |
| `vector operator-(const vector& other) const` | Поэлементное вычитание векторов. |
| `T operator*(const vector& other) const` | Скалярное произведение векторов. |
| `vector operator*(const T& scalar) const` | Умножение вектора на скаляр. |
| `vector operator/(const T& scalar) const` | Деление вектора на скаляр. |
| `template<typename T> vector<T> operator*(const T& scalar, const vector<T>& vec)` | Умножение скаляра на вектор. |

## Обработка ошибок

- `std::out_of_range` — выход за границы вектора при обращении по индексу.
- `std::logic_error` — несовпадение размерностей векторов в операциях сложения, вычитания и скалярного произведения.
- `std::invalid_argument` — деление на нулевой скаляр.

## Особенности реализации

- Для целых типов случайные значения генерируются через `std::uniform_int_distribution`.
- Для вещественных типов используется `std::uniform_real_distribution`.
- Для комплексных типов отдельно генерируются действительная и мнимая части.
- Скалярное произведение для комплексных чисел вычисляется с сопряжением первого вектора.
- Компиляторные предупреждения:
  - Clang/GCC: `-Wall -Wconversion -Wextra -Wpedantic`;
  - MSVC: `/W4 /utf-8`.
