# Лабораторная работа №1. Вариант 1. Векторы

Шаблонный класс вектора произвольной размерности на C++23.  
Тип элемента вектора задаётся параметром шаблона `T`.

## Возможности

- Шаблонный класс `vector<T>` произвольной размерности.
- Поддержка типов элементов:
  - `int`
  - `float`
  - `double`
  - `std::complex<float>`
  - `std::complex<double>`
- Конструктор с размерностью и значением для заполнения.
- Конструктор со случайными значениями (размерность, нижняя и верхняя границы).
- Доступ к элементу по индексу через `operator[]` с проверкой границ.
- Операторы сложения и вычитания векторов.
- Оператор скалярного произведения векторов.  
  Для комплексных типов используется сопряжение первого вектора: `sum(conj(a_i) * b_i)`.
- Оператор умножения вектора на скаляр; коммутативность обеспечена свободной функцией `operator*`.
- Оператор деления вектора на скаляр.
- Операторы сравнения на равенство и неравенство с заданной точностью (`epsilon`).
- Оператор вывода в поток `std::ostream` без использования C-шных потоков.
- Метод `length()` — евклидова норма вектора.
- Метод `size()` — размерность вектора.
- Интерактивное консольное меню для работы с векторами.

## Решаемая задача

**Вариант 1.** Найти радиус-вектор биссектрисы треугольника, заданного радиус-векторами `a` и `b`.

Решение вынесено в перегруженные функции `task()`:

- для арифметических типов (`int`, `float`, `double`) результат приводится к `vector<double>`;
- для комплексных типов результат сохраняет исходный тип `vector<std::complex<U>>`.

Биссектриса вычисляется как сумма нормированных векторов `a / |a| + b / |b|`.  
Если один из векторов нулевой или векторы противоположны, выбрасывается `std::logic_error`.

## Основное API класса `vector<T>`

| Метод | Описание |
|---|---|
| `vector(std::size_t size, const T& value)` | Создаёт вектор размера `size`, заполненный значением `value`. |
| `vector(std::size_t size, const T& lower, const T& upper)` | Создаёт вектор размера `size`, заполненный случайными значениями из `[lower, upper]`. |
| `T& operator[](std::size_t index)` | Доступ к элементу по индексу для чтения и записи. |
| `const T& operator[](std::size_t index) const` | Доступ к элементу по индексу только для чтения. |
| `vector operator+(const vector& other) const` | Поэлементное сложение векторов. |
| `vector operator-(const vector& other) const` | Поэлементное вычитание векторов. |
| `T operator*(const vector& other) const` | Скалярное произведение. |
| `template<typename S> vector operator*(const S& scalar) const` | Умножение вектора на скаляр. |
| `template<typename S> vector operator/(const S& scalar) const` | Деление вектора на скаляр. |
| `bool operator==(const vector& other) const` | Сравнение на равенство с точностью `epsilon`. |
| `bool operator!=(const vector& other) const` | Сравнение на неравенство. |
| `std::size_t size() const` | Размерность вектора. |
| `double length() const` | Евклидова норма вектора. |

Вне класса:

| Функция | Описание |
|---|---|
| `template<typename T, typename S> vector<T> operator*(const S&, const vector<T>&)` | Умножение скаляра на вектор (коммутативность). |
| `template<typename T> std::ostream& operator<<(std::ostream&, const vector<T>&)` | Вывод вектора в поток. |
| `task(const vector<T>&, const vector<T>&)` | Радиус-вектор биссектрисы (перегрузки для арифметических и комплексных типов). |

## Интерактивное меню

При запуске программа предлагает выбрать тип элемента вектора:

```text
Select the vector element type:
  [1] int
  [2] float
  [3] double
  [4] complex<float>
  [5] complex<double>
```

Затем открывается меню для работы с двумя векторами:

```text
[1] Create a vector: dimension and fill value
[2] Create a vector: dimension, lower and upper bounds (random)
[3] Replace an element by index
[4] Add two vectors
[5] Subtract two vectors
[6] Scalar product of two vectors
[7] Multiply a vector by a scalar
[8] Divide a vector by a scalar
[9] Build the bisector of two vectors (task)
[10] Exit
```

Все ошибки ввода и исключения обрабатываются и выводятся через `std::cout`.

## Обработка ошибок

- `std::out_of_range` — выход за границы вектора при обращении по индексу.
- `std::logic_error` — несовпадение размерностей векторов в операциях сложения, вычитания, скалярного произведения и `task()`; нулевой или противоположный вектор в `task()`.
- `std::invalid_argument` — нижняя граница превышает верхнюю в конструкторе со случайным заполнением; деление на нулевой скаляр.

## Особенности реализации

- Для целых типов случайные значения генерируются через `std::uniform_int_distribution`.
- Для вещественных типов используется `std::uniform_real_distribution`.
- Для комплексных типов отдельно генерируются действительная и мнимая части.
- Скалярное произведение для комплексных чисел вычисляется с сопряжением первого вектора: `sum(conj(a_i) * b_i)`.
- Сравнение вещественных и комплексных чисел выполняется с точностью `vector<T>::epsilon` (статическое поле, `1e-9`).
- Проверка типа выполняется на этапе компиляции через `if constexpr` и `std::enable_if_t`; `typeid` и `dynamic_cast` не используются.
- Выделение памяти в конструкторе со случайным заполнением выполняется после проверки границ, чтобы избежать утечки при выбросе исключения.
- Компиляторные предупреждения:
  - Clang/GCC: `-Wall -Wconversion -Wextra -Wpedantic`;
  - MSVC: `/W4 /utf-8`.

### Общие требования к лабораторной работе №1

1. Нельзя использовать контейнеры STL, кроме `std::string` и `std::complex`.
2. Класс копируемый и непосредственно управляет выделяемым ресурсом.
3. Класс предоставляет операторы сравнения на равенство и неравенство; сравнение вещественных чисел выполняется с заданной точностью (например, через константное статическое поле класса).
4. Класс перегружает оператор вывода без использования C-шных потоков.
5. При некорректности аргументов выбрасываются исключения через `<stdexcept>` (обращение по несуществующему индексу, сложение векторов разного размера и т. п.).
6. Весь ввод-вывод осуществляется исключительно через `std::cin` и `std::cout`, без явного или неявного использования `stdin` и `stdout`.
7. Разрешено пользоваться генераторами случайных чисел из `<random>`.
8. Логика продумывается так, чтобы наибольшее число операторов и методов переиспользовалось в последующих методах.
9. Решение задач расположено вне класса.
10. В `main()` демонстрируется работоспособность всех операторов и методов на случайно сгенерированном объекте класса.
11. Проверка типов выполняется на этапе компиляции, а не во время выполнения. Для различения операций над данными разных типов используются шаблоны и перегрузка операторов. Запрещена проверка и выбор поведения по типу данных во время выполнения (`typeid`, `dynamic_cast`, ветвление по тегу/enum типа и т. п.).
